01   The tools

📓
OPEN SOURCE

Joplin

markdown notes · end-to-end encrypted · local-first

Your private, offline-first notebook. Joplin stores notes as Markdown files you own entirely, with optional E2E-encrypted sync via Dropbox, OneDrive, or a self-hosted server. Perfect for raw captures, personal journals, and reference material you never want locked in a vendor's cloud.

  • End-to-end encryption at rest and in transit
  • Plugin ecosystem — backlinks, kanban, rich editor
  • Web clipper to save pages directly into notebooks
  • Full-text search with tags and notebooks hierarchy
  • Sync via Joplin Cloud, Dropbox, WebDAV, or S3
  • Export to PDF, HTML, or raw Markdown at any time
🗂️
CONNECTED

Notion

workspace · databases · team collaboration

The connective tissue of projects and teams. Notion's block-based editor pairs with relational databases, views (table, board, calendar, gallery), and real-time collaboration. Use it for project wikis, roadmaps, meeting notes that need to link back to tasks, or any structured knowledge that benefits from multiple views.

  • Relational databases with linked views and filters
  • Templates for projects, CRMs, content calendars
  • Notion AI for summarising, drafting, and Q&A
  • Share pages publicly with a single link
  • API for automations and external integrations
  • Team comments, mentions, and version history
🖥️
CLI + VSCODE

Marp

markdown → slides · HTML · PDF · PPTX

Turn Markdown into stunning presentation decks without ever leaving your editor. Marp renders slides via a thin layer of fenced directives on top of standard Markdown. Write content fast, version control your decks in Git, and export to HTML for the web, PDF for sharing, or PPTX for Office compatibility.

  • Write slides in pure Markdown with front-matter directives
  • Built-in themes — default, gaia, uncover — plus custom CSS
  • VS Code extension with hot-reload preview
  • CLI: marp slides.md --html --pdf
  • Export to HTML, PDF, and PPTX from one source file
  • Git-diffable source — no binary PPTX in your repo

02   Workflow

1

Capture in Joplin

Clip articles, jot fleeting thoughts, and log meeting minutes using the web clipper or mobile app. Everything lands in your Inbox notebook.

2

Process & organise

Review your inbox daily. Tag notes, assign to notebooks, link related ideas with [[backlinks]]. Distil raw captures into atomic notes.

3

Structure in Notion

For project-level knowledge, move refined notes to Notion databases. Link tasks, wikis, and roadmaps together. Collaborate with teammates.

4

Present with Marp

When a presentation is needed, draft slides in Markdown from your existing notes. Commit to Git. Export to PDF or HTML for delivery.

03   Tips & snippets

Joplin

Backlinks plugin

Install the Joplin Backlinks plugin to get a panel showing every note that links to the current one — turning your notebook into a personal wiki.

[[Note Title]] // creates a backlink

Joplin

External sync via WebDAV

Self-host Joplin sync with Nextcloud or any WebDAV server. Go to Tools → Options → Synchronisation and paste your WebDAV URL.

Notion

Linked databases

Create a "master tasks" database and embed filtered linked views in each project page. One source of truth, many contextual views.

Notion

Import from Joplin

Export Joplin notes as Markdown, then import the folder into Notion via Settings → Import → Text & Markdown. Formatting is preserved.

Marp

Custom theme in one file

Add a style block at the top of your Marp file to override theme CSS without creating a separate file.

--- marp: true theme: default --- <style> section { background: #0e0e10; color: white; } </style>

Marp

GitHub Actions auto-export

Use the marp-action GitHub Action to auto-export PDF slides on every push to main.

- uses: marp-team/marp-action@v2 with: input: slides.md output: slides.pdf
